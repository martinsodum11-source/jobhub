# Contributing to JobHub

Thank you for your interest in contributing to JobHub! 🎉

JobHub is an open-source project, and contributions of all kinds are welcome.

## How to Contribute

### 1. Fork the Repository

Fork the JobHub repository to your own GitHub account.

### 2. Clone Your Fork

Clone your fork to your computer:

```bash
git clone https://github.com/martinsodum11-source
```

Then move into the project:

```bash
cd jobhub
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Create a Branch

Create a branch for your contribution:

```bash
git checkout -b feature/your-feature-name
```

Use a clear branch name that describes your change.

Examples:

```text
feature/job-filters
feature/dark-mode
fix/mobile-navbar
fix/job-search
```

### 5. Make Your Changes

Make your changes and test them locally.

Run the development server:

```bash
npm run dev
```

Make sure the application works correctly before submitting your contribution.

### 6. Commit Your Changes

Create a clear commit message:

```bash
git add .
git commit -m "Add job filtering"
```

### 7. Push Your Branch

```bash
git push origin feature/your-feature-name
```

### 8. Open a Pull Request

Open a pull request on GitHub and explain:

* What you changed
* Why you made the change
* How you tested it

## Code Guidelines

Please try to:

* Keep components small and reusable
* Use clear and descriptive variable names
* Follow the existing project structure
* Keep styling consistent with Tailwind CSS
* Avoid unnecessary dependencies
* Test your changes before opening a pull request

## Reporting Bugs

If you find a bug, please open a GitHub issue and include:

* A description of the problem
* Steps to reproduce it
* What you expected to happen
* What actually happened
* Screenshots if applicable

## Suggesting Features

Feature suggestions are welcome.

Please explain:

* What the feature should do
* Why it would be useful
* How you think it could improve JobHub

## Questions

If you're unsure about something, open an issue and ask.

Every contribution helps improve JobHub. Thank you for being part of the project! ❤️
